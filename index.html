Quick Start Guide

Get up and running with MCODE in minutes.

1. Install the SDK

npm install @mcode/node

2. Send your first email

import { MCode } from '@mcode/node';

         const mcode = new MCode('YOUR_API_KEY');
         await mcode.emails.send({
           from: 'you@example.com',
           to: 'user@example.com',
           subject: 'Hello World',
           html: '<p>Congrats on sending your first email!</p>'
         });
